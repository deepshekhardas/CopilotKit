The **Built-in Agent** is CopilotKit's simplest agent option. It connects directly to an LLM with full support for tools, generative UI, shared state, and all CopilotKit features — without requiring an external agent framework like LangGraph or CrewAI.

It supports most popular models from OpenAI, Anthropic, and Google out of the box.

## When to use Built-in Agent

- **Quick setup** — no external agent framework to configure or deploy
- **Chat + tools** — your use case is primarily conversational with frontend and server tools
- **Direct model access** — you want to use OpenAI, Anthropic, or Google models without a LangGraph/CrewAI layer
- **Prototyping** — rapidly build and iterate on agent experiences

<Callout type="info">
If you need complex agent graphs, human-in-the-loop interrupt flows, or multi-agent orchestration with custom routing, consider [LangGraph](/langgraph) instead.
</Callout>
