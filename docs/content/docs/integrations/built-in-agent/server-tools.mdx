## What are Server Tools?

Server tools are functions that run on your backend that the Built-in Agent can invoke. They're defined using `defineTool()` with Zod schemas for type-safe parameters.

## Defining a Tool

```typescript title="src/copilotkit.ts"
import { BuiltInAgent, defineTool } from "@copilotkitnext/agent";
import { z } from "zod";

const getWeather = defineTool({
  name: "getWeather",
  description: "Get the current weather for a city",
  parameters: z.object({
    city: z.string().describe("The city name"),
  }),
  execute: async ({ city }) => {
    // Your implementation here
    return { temperature: 72, condition: "sunny", city };
  },
});

const builtInAgent = new BuiltInAgent({
  name: "assistant",
  model: "openai:gpt-4o",
  tools: [getWeather],
});
```

## Tool Response

Tools can return any JSON-serializable value. The agent will use the response to continue the conversation.

```typescript
const searchDocs = defineTool({
  name: "searchDocs",
  description: "Search the documentation",
  parameters: z.object({
    query: z.string(),
  }),
  execute: async ({ query }) => {
    const results = await search(query);
    return { results, count: results.length };
  },
});
```
