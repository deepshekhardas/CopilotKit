<Steps>
<Step>
### Install CopilotKit

```bash
npm install @copilotkit/react-core @copilotkit/react-ui @copilotkitnext/agent
```
</Step>

<Step>
### Set up the Built-in Agent

Create a Built-in Agent on your backend:

```typescript title="src/copilotkit.ts"
import { CopilotRuntime } from "@copilotkit/runtime";
import { BuiltInAgent } from "@copilotkitnext/agent";

const builtInAgent = new BuiltInAgent({
  name: "assistant",
  description: "A helpful AI assistant",
  model: "openai:gpt-4o",
});

const runtime = new CopilotRuntime({
  agents: [builtInAgent],
});
```
</Step>

<Step>
### Add the CopilotKit provider

Wrap your app with `CopilotKit` and add a chat component:

```tsx title="app/layout.tsx"
import { CopilotKit } from "@copilotkit/react-core";
import "@copilotkit/react-ui/v2/styles.css";

export default function RootLayout({ children }) {
  return (
    <CopilotKit runtimeUrl="/api/copilotkit">
      {children}
    </CopilotKit>
  );
}
```

```tsx title="app/page.tsx"
import { CopilotChat } from "@copilotkit/react-core/v2";

export default function Page() {
  return (
    <CopilotChat
      labels={{
        modalHeaderTitle: "AI Assistant",
        welcomeMessageText: "How can I help you today?",
      }}
    />
  );
}
```
</Step>

<Step>
### Start chatting!

Run your app and start chatting with your Built-in Agent.
</Step>
</Steps>
