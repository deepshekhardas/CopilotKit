## Summary
- Adds an optional `agentId` field to `useAgentContext` so context can be scoped to a specific agent
- Context with an `agentId` is only forwarded to that agent; global context (no `agentId`) is sent to all agents
- Mirrors the existing `agentId` scoping behavior of `useFrontendTool`
- Introduces `FrontendContext` type (extends AG-UI `Context` with optional `agentId`), following the `FrontendTool` naming pattern
